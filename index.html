🔒 Privacy Notice — How CyberGhost Works

All scanning is performed entirely in your browser using JavaScript. Your text is never sent to any server, cloud service, or external API. CyberGhost does not store, log, or transmit your input for any purpose.

No external scripts or fonts are loaded. The application runs entirely from its local files after initial page load, with no network calls during scanning.

Important limitations: Detection uses regular expression pattern matching. It may miss novel formats and may produce false positives. Results are educational indicators, not security guarantees. No pattern-matching tool can detect every possible sensitive format or confirm the authenticity of matched data.

Memory note: While the page is open, text you enter resides temporarily in browser memory. Closing the tab removes it. CyberGhost does not write scanned text to localStorage, sessionStorage, cookies, or any persistent storage.
